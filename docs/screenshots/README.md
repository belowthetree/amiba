# README 截图放置说明

将截图 PNG 文件放在本目录，README 引用的文件名约定如下：

| 文件名 | 内容 | 建议 |
|--------|------|------|
| `chat.png` | AI 对话页 | 有一条真实对话记录的效果最佳 |
| `services.png` | 服务浏览页 | 展示已安装服务列表 |
| `service-detail.png` | 服务运行（iframe 沙箱） | 任一服务的运行界面 |
| `settings.png` | 设置页 | 主题/供应商配置界面 |

- 建议桌面窗口截图，宽度 1280px 左右，PNG 格式
- 文件名必须与上表完全一致，否则 README 中图片无法显示
- 准备好后删除本说明文件即可
